# Currency Converter 💱

A responsive currency converter built using HTML, CSS, and JavaScript. It allows users to convert currencies using live exchange rates through a simple and user-friendly interface.

## Features

- Live currency exchange rates
- Searchable currency selection
- Instant currency swapping
- Local caching
- Conversion history
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ridmi18/Currency-Converter.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
